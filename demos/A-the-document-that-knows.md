# A. The document that knows when it's wrong

**Audience:** anyone who has ever distrusted a stale doc — the universal pitch.
**Unique property staged:** an artifact that knows what it rests on, and reacts when a premise dies.

## Scene (3 minutes)

1. A one-page decision brief renders from the workroom — looks like a
   normal document; every section rests on claim events.
2. In a second window, someone supersedes one upstream claim: *the
   cost basis changed.*
3. **The wow:** within a second, the three downstream sections flare
   stale in the first window — each with a one-click provenance walk
   ending at the superseding event and its author.
4. An agent drafts the repair as a proposal; a human ratifies; the
   flares clear.
5. Coda (demo E folded in): `git clone`, verify offline, "and if you
   don't like how it's governed, you leave with everything."
