Omission controls for stage S1 (layer 1 association and cleanup reporting).

Each guard was removed or inverted in a scratch copy of the worktree under
.../scratchpad/20819/mutants/<name>, made with cp -R and never inside the
repository. The patch scripts are in .../scratchpad/20819/patches. Each row
records the test that failed with the guard gone. All seventeen mutants were
killed; none survived. The whole set was re-run after the code was renamed
away from the word "lane", which the design note reserves for the existing
work query lane, so these results describe the shipped names.

m1-any-commit
  Guard: corroboration reads only artifacts naming this exact commit
        (associationGrader.commitEvidence, internal/app/association.go)
  Mutation: evidence is gathered from every artifact regardless of its commit
  Killed by: TestForgedTrailerAndCopiedAuthorIdentStayClaimed
             TestAssociationSeparatesRecutsOfOneGoverningRecord

m2-any-governing
  Guard: evidence must reach the record the commit claims
        (associationGrader.corroborate)
  Mutation: the governing-record comparison is deleted
  Killed by: TestEvidenceMustReachTheRecordTheCommitClaims

m3-foreign-resolved
  Guard: a canonical identifier of another genesis is carried as typed
        (associationGrader.grade, eventref.FormExternal branch)
  Mutation: the foreign branch is made unreachable, so the value is resolved
  Killed by: TestAssociationCarriesAForeignGenesisAsTyped

m4-branch-corroborated
  Guard: corroboration attaches to a commit, never to a branch
        (gradeAssociationRow demotion when CorroboratedAt is not the head)
  Mutation: any corroborated commit on the lineage corroborates the tip
  Killed by: TestCorroborationAttachesToTheCommitNotTheBranch

m5-no-pending-protection
  Guard: a pending decision protects the checkout holding its subject
        (classifyWorktreeRows, PendingDecision case)
  Mutation: the classification case is deleted
  Killed by: TestAPendingDecisionProtectsItsCandidateAndNothingElse
             TestWorktreeCapturedRoomWithinOriginalBudget (differential oracle)

m6-retired-artifact-ignored
  Guard: a retired artifact is still a pending decision's subject
        (pendingDecisionScan.observe)
  Mutation: retired artifact statements are skipped
  Killed by: TestAPendingDecisionProtectsItsCandidateAndNothingElse

m7-no-refless-protection
  Guard: a head no ref points at protects its checkout
  Mutation: the classification case is deleted
  Killed by: TestCheckoutReportingCoversDirtyLockedSymlinkedAndOutOfScopePaths

m8-no-containment-protection
  Guard: a checkout outside the root or behind a symbolic link is protected
  Mutation: the classification case is deleted
  Killed by: TestCheckoutReportingCoversDirtyLockedSymlinkedAndOutOfScopePaths

m9-no-duplicate-report
  Guard: two checkouts at one head are reported at inventory time
        (LocalWorktrees, internal/app/app.go)
  Mutation: DuplicateHead is always false
  Killed by: TestInventoryReportsLinkedCheckoutsAndDuplicateHeads

m10-frontier-only-cache
  Guard: the cache key pairs the frontier with the ref inventory digest
  Mutation: the digest is replaced with a constant
  Killed by: TestAssociationRemeasuresAfterBranchMovementAndRename
             TestAssociationCachesUnderTheFrontierAndRefDigest

m11-partial-on-exhaustion
  Guard: budget exhaustion discards the whole batch
        (associate row loop and final budget.take(0))
  Mutation: the pass returns whatever it managed, marked complete
  Killed by: TestAssociationDiscardsTheWholeBatchOnBudgetExhaustion

m12-stale-is-settled
  Guard: staleness is not settlement (settledCommitment)
  Mutation: "stale" is added to the settled word list
  Killed by: TestAStaleGoverningRecordProtectsAndASettledOneDoesNot

m13-no-object-verification
  Guard: every commit a trailer is read from is re-verified against its hash
        (Store.Lineage sharing refuseMalformedCommits)
  Mutation: the verification call is deleted
  Killed by: TestLineageRefusesACommitObjectGitFsckCallsMalformed

m14-no-first-parent
  Guard: the lineage walk follows first parents only
  Mutation: --first-parent is dropped from the log
  Killed by: TestLineageFollowsFirstParentToTheBoundary

m15-cap-raised
  Guard: the checkout inventory cap refuses rather than truncating
  Mutation: the listing is truncated to 128 entries instead of refusing
  Killed by: TestTheCheckoutInventoryCapRefusesRatherThanTruncating

m16-ambiguity-picks-a-winner
  Guard: an ambiguous selector refuses and never picks a candidate
  Mutation: the first candidate becomes the governing record
  Killed by: TestAssociationReportsAmbiguousAndMissingIdentityWithoutChoosing

m17-no-membership-check
  Guard: a canonical identifier must name a record this workroom holds
        (Set.Resolvable check in associationGrader.grade)
  Mutation: the membership check is deleted
  Killed by: TestAssociationReportsAmbiguousAndMissingIdentityWithoutChoosing
