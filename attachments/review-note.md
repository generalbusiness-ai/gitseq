Show the expected and observed object IDs and the next remaining action. Permit safe retries using ordinary Git operations and the existing workroom mechanisms. Avoid another cache, inferred authority, or cleanup based on age or a closed row.

A small acceptance set can use the W1 example: source present but receipt missing; sequence behind; remote moving concurrently; publication retried after a lost response; CI still pending; and an owned checkout versus a protected or uncertain one. Each case should produce an accurate remaining-action result using current rules. The existing binding-preparation design should remain the authority for resolving implementation/review relationships, so this follow-up does not introduce a second resolver.

Meanwhile, apply the practices already agreed: file executable assignments on current prerequisites; retain same-outcome corrections; distinguish evidence gathering from source delivery; and report an event as filed only after its effective result is known.
