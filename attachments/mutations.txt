Mutation evidence for the notification read-position regression
===============================================================

Method
------
The worktree's ui/ tree (source, tests, node_modules) was copied with cp -R to
a scratch directory outside the repository:

  /private/tmp/claude-501/.../scratchpad/mutant/ui

Pristine copies of ui/src/components/TopBar.tsx and ui/src/lib/memory.ts were
kept beside it. Each of the four mutations from notification-storage-mutations.diff
was applied on its own to the scratch copy, the focused test file was run there
with `node --test test/notifications.test.mjs`, and the source was restored from
the pristine copies before the next mutation. No mutation was ever applied
inside the repository or the worktree, and no `git` command ran in the copy.

The new tests are:
  A. "a saved read position decides what is unread at mount and every reading is
      written back"
  B. "read positions stay apart by room and by actor"

Baseline
--------
Unmutated scratch copy: rc=0, 7 tests, 7 pass, 0 fail (the five pre-existing
notification tests plus A and B).

Assertion failures versus build errors
--------------------------------------
Every failure below is a runtime AssertionError raised by node:assert inside a
mounted React tree: node reports `code: 'ERR_ASSERTION'` with an actual and an
expected value. None of the four runs produced a syntax, transform, module
resolution or type error: the mutated modules loaded and rendered, and the five
pre-existing notification tests stayed green in every run, which they could not
have done if the module had failed to build. Grep over the four run logs for
SyntaxError, "Transform failed", TypeError, ERR_MODULE, "Cannot find" and
esbuild diagnostics returns zero matches; ERR_ASSERTION is the only error kind
present.

Two of the mutations change the storage key, which also makes the independently
seeded position in test A invisible, so those runs fail in both tests. The
boundary each mutation is meant to be caught at is named below; in every case
the assertion at that boundary is among the failures.
